## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/mealy-moore-simulator.git
cd mealy-moore-simulator
```

### 2. Create the React Project

If you downloaded the `.jsx` file separately, create the Vite project:

```bash
npm create vite@latest mealy-moore-simulator -- --template react
```

### 3. Install Dependencies

```bash
cd mealy-moore-simulator
npm install
npm install lucide-react
```

### 4. Add the Simulator Code

Copy the downloaded:

```text
mealy-moore-simulator.jsx
```

into:

```text
src/App.jsx
```

Replace the existing `App.jsx`.

### 5. Start the Application

```bash
npm run dev
```

### 6. Open in Browser

Open:

```text
http://localhost:5173
```

🎉 The **Mealy & Moore Machine Simulator** is now running locally.
